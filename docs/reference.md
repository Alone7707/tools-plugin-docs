# 规范参考

## 第三方插件交付链路

```text
创建 Vue + Vite 插件工程
  ↓
持续构建 dist，并在客户端登记调试
  ↓
执行 pnpm build 生成正式 dist 插件包
  ↓
上传整个 dist 目录
  ↓
服务端校验并生成草稿
  ↓
开发者送审
  ↓
管理员发布
  ↓
商店目录可见，客户端按 entryUrl 动态加载
```

## 硬性限制

| 项目 | 限制 |
| --- | --- |
| 文件数量 | 不超过 20 个 |
| 单文件大小 | 不超过 512 KB |
| 包总大小 | 不超过 2 MB |
| 目录深度 | 不超过 3 层 |
| 入口扩展名 | `.js` 或 `.mjs` |
| 资源扩展名 | `.js`、`.mjs`、`.json`、`.css`、`.md`、`.svg`、`.txt`、`.png`、`.jpg`、`.jpeg`、`.webp`、`.gif` |
| 路径字符 | 仅允许字母、数字、`_`、`-`、`.`、`/`；禁止绝对路径和 `..` |

## 运行时硬约束

- 入口模块必须是 ESM，并导出 Vue 组件。
- 源码可正常从 `vue` 导入 API；模板构建时映射到宿主 `window.Vue`，插件不可重复打包 Vue。
- 插件运行在渲染层，不提供 `require`、`fs`、`electron` 或 `ipcRenderer`。
- `api` 可能为空，必须按能力检测后调用。
- 版本目录不可变，代码或清单发生变化时必须递增 `version`。
- 自定义样式使用 `plugin-` 前缀；宿主标题栏、返回按钮和分离行为由宿主负责。

## 事实来源

运行时契约对应客户端的 `RemotePluginHost` 与插件 API 工厂；清单校验对应服务端的商店 manifest 校验逻辑；Electron bridge 对应 preload 的 `window.atoolbox` 暴露对象。本独立站点记录的是面向插件开发者的公开契约，不承诺内部 IPC 通道稳定。
